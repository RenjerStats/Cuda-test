# NIR Alignment Rules

## Check For Drift

- Feature names that no longer match the planned module map
- Metrics that differ from the planned measurement set
- Experiment claims that lack a corresponding artifact in `reports/`
- Scope growth that violates the declared NIR boundaries

## Keep In Sync

- Acceptance criteria in work items
- Benchmark methodology in `docs/methodology/`
- Terminology for modules, metrics, and experiment outputs

## Escalate

- Rewording that changes the research claim
- Added performance claims without evidence
- Added modules or experiment types that extend the declared scope
