Демонстрация полного рабочего процесса cuda_test
===============================================

Этот каталог был сгенерирован примером examples/full_workflow_demo.cu.

Артефакты
---------
- pipeline/pipeline_report.html : самостоятельный человекочитаемый отчет
- pipeline/pipeline_report.json : машиночитаемый отчет по одному пайплайну
- pipeline/pipeline_report.csv  : плоская сводка для таблиц
- pipeline/benchmark.json/.csv  : сырая статистика измерений
- pipeline/autotune.json/.csv   : все принятые кандидаты автотюнинга и победитель
- suite/suite_report.html       : одна страница с несколькими разделами по ядрам
- suite/json/*.json             : один JSON-файл на каждый отчет по ядру
- suite/csv/*.csv               : один CSV-файл на каждый отчет по ядру

-------------------
